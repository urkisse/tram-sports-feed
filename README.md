# tram-sports-feed

A short list of upcoming top sports events (padel, boxing, tennis) for a home
display. `events.json` is rewritten weekly by an agent following [AGENT.md](AGENT.md).

## Tram timetable

`tram/<stop_id>.json` holds departures towards Alicante centre for every TRAM d'Alacant stop, generated by
`tools/tram_schedule.py` from the latest GTFS (Mobility Database feed mdb-1039). The GitHub Action in
`.github/workflows/tram.yml` refreshes it daily and commits only when the timetable changes.
